# 📸 GetBackAlbum Bot — безопасная группировка медиа в Telegram

Бот автоматически собирает отправленные фото и видео в альбомы по 10 штук, удаляя исходные сообщения. Соблюдает лимиты Telegram (flood control) и работает 24/7 на бесплатном хостинге Render.

## 🚀 Возможности

- 📸 Принимает фото и видео, складывает в очередь.
- 🖼️ Группирует по 10 файлов в один медиа-альбом.
- 🗑️ Удаляет исходные сообщения (чтобы не засорять чат).
- ⚡ Автоматическая задержка между отправками (3 секунды) — защита от ограничений.
- 🔄 Повторная отправка при ошибках (flood control, таймауты).
- ⏸️ Команды для паузы, очистки очереди, принудительной отправки.
- 🌐 Работает через **webhook** (Render + aiohttp).
- 🔔 UptimeRobot поддерживает бота в активном состоянии (не засыпает).

## 📋 Команды

| Команда       | Описание                                                                 |
|---------------|--------------------------------------------------------------------------|
| `/start`      | Приветствие и список команд.                                             |
| `/flush`      | Немедленно отправить все накопленные файлы (с соблюдением лимитов).      |
| `/clear`      | Очистить очередь для текущего пользователя.                              |
| `/status`     | Показать размер очереди, активность обработки, время до следующей отправки. |
| `/pause`      | Приостановить автоматическую обработку (можно возобновить `/flush`).     |
| `/help`       | Показать справку.                                                        |

## ⚙️ Установка и запуск

### 1. Локально (для тестирования)

```bash
git clone https://github.com/TeaMaker1937/GetBackAlbum.git
cd GetBackAlbum
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Создайте файл `.env` или добавьте переменную окружения:
```
BOT_TOKEN=ваш_токен_от_BotFather
```

Запуск:
```bash
python app.py
```

### 2. Деплой на Render (бесплатно, 24/7)

1. **Подготовьте репозиторий** на GitHub с файлами:
   - `app.py` (основной код бота)
   - `requirements.txt`
   - `runtime.txt` (содержит `python-3.11`)

2. **Создайте Web Service** на [render.com](https://render.com):
   - Environment: `Python`
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python app.py`
   - Добавьте переменную окружения `BOT_TOKEN`

3. **Установите вебхук** (один раз вручную):
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/setWebhook?url=https://<имя_сервиса>.onrender.com/webhook
   ```

4. **Настройте UptimeRobot** (чтобы бот не засыпал):
   - Зарегистрируйтесь на [UptimeRobot](https://uptimerobot.com)
   - Добавьте HTTP-монитор:
     - URL: `https://<имя_сервиса>.onrender.com/`
     - Интервал: `5 минут`
   - Сервис будет пинговать бота, предотвращая сон Render.

## 🔧 Конфигурация

Все настройки находятся в начале файла `app.py`:

```python
BATCH_SIZE = 10            # размер альбома
MIN_SEND_INTERVAL = 3.0    # минимальная задержка между отправками (сек)
MAX_QUEUE_SIZE = 1000      # максимальный размер очереди на пользователя
FLOOD_RETRY_DELAY = 15     # пауза при ошибке flood control (сек)
```

## 🛡️ Особенности работы

- **Очередь** хранится в памяти (для каждого пользователя отдельно). При перезапуске бота очередь сбрасывается.
- **Удаление сообщений** требует прав на удаление (бот должен быть администратором в группе или писать в личку).
- **Webhook** — все обновления приходят на один эндпоинт `/webhook`, что экономит ресурсы.
- **Health check** — корневой путь `/` возвращает `OK`, используется UptimeRobot.
